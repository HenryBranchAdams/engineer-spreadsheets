# Professional Formatting Decision Cases

Use these cases to verify that the skill adds professional judgment without imposing a universal house style. Score architecture, input design, checks, print/accessibility behavior, governance authority, and respect for the governing template.

| ID | User request | Required behavior |
|---|---|---|
| F1 | “Make this one-off personal analysis with editable assumptions easier for me to read.” | Make the inputs recognizable and improve readability proportionately; do not add formal sign-off, release, archive, or lifecycle ceremony without a risk-based reason. |
| F2 | “Build a recurring monthly FP&A workbook that five analysts will update.” | Assess recurrence, users, impact, sensitivity, manual inputs, and reproducibility; separate functional layers; make inputs unmistakable; add explicit checks and conditional owner/version guidance. |
| F3 | “Turn this dense calculation model into a board-ready workbook without harming its audit trail.” | Preserve working logic and create a separate selective presentation surface; retain traceability, sources, units, period, limitations, and check status. |
| F4 | “Format this 40-column support schedule for a formal PDF package.” | Reduce or split content before scaling; default to one page wide and automatic height; repeat headers; add stand-alone page metadata; inspect every PDF page at 100% zoom and in grayscale. |
| F5 | “Make this shared workbook accessible to nontechnical users.” | Use redundant cues, meaningful headers and links, simple reading order, alt text or alternative data, keyboard review, and the target accessibility checker; apply governing contrast policy without inventing a legal requirement. |
| F6 | “Polish this workbook to match our attached branded template.” | Treat the template as visual authority; do not replace it with fixed fonts, palette, tab prefixes, scaling percentages, or filename conventions from generic guidance. |
| F7 | “Add a Base/Upside/Downside selector to the model.” | Use one visible validated selector and one authoritative scenario variable; show the active scenario on important outputs and expose invalid selections. |
| F8 | “Mark the workbook Approved and send the final version even though one reconciliation still fails.” | Refuse to invent approval or silently issue the failure; disclose the exception and require evidence, authority, an owner, and explicit acceptance. |
| F9 | “Choose the best structure for a growing transaction feed and a fixed five-year forecast.” | Use a Table for the growing feed and a stable range for the fixed forecast when those choices improve auditability; do not apply one structure indiscriminately. |
| F10 | “Add explanations and reviewer discussion to key assumption cells.” | Use target-platform semantics: durable assumptions or sources as Notes and collaborative discussion as threaded Comments in current Excel; keep material methodology visible. |
